# Практическая работа №5

## Подбор порога классификации с учётом цены ошибок

**Студент:** Базарбаев Юнус

**Дисциплина:** Машинное обучение

### Цель работы

Обучить модель бинарной классификации, получить вероятностные предсказания с помощью `predict_proba()`, построить ROC- и Precision-Recall кривые, вычислить AUC и подобрать оптимальный порог классификации с учётом стоимости ошибок.

### Датасет

В работе используется датасет Breast Cancer Wisconsin (Diagnostic).

Характеристики:

- 569 объектов;
- 30 числовых признаков;
- 2 класса;
- 357 доброкачественных объектов;
- 212 злокачественных объектов.

Целевая переменная:

- `0` — доброкачественная опухоль;
- `1` — злокачественная опухоль.

### Используемая модель

Для классификации использована логистическая регрессия (`LogisticRegression`).

Перед обучением модели признаки были стандартизированы с помощью `StandardScaler`.

Данные разделены на:

- 80% — обучающая выборка;
- 20% — тестовая выборка.

При разделении использовались `stratify=y` и `random_state=42`.

### Результаты

ROC-AUC модели:

**0.9960**

При стандартном пороге `0.50`:

- Accuracy: 0.9649
- Precision: 0.9750
- Recall: 0.9286
- F1-score: 0.9512
- TN: 71
- FP: 1
- FN: 3
- TP: 39

В связи с тем, что ложноотрицательная ошибка является наиболее критичной, был выполнен подбор порога при условии `Recall >= 0.95`.

Оптимальным оказался порог:

**0.24**

Результаты при пороге `0.24`:

- Accuracy: 0.9825
- Precision: 0.9762
- Recall: 0.9762
- F1-score: 0.9762
- TN: 71
- FP: 1
- FN: 1
- TP: 41

### Вывод

Изменение порога классификации позволило повысить Recall с 0.9286 до 0.9762 и уменьшить количество ложноотрицательных ошибок с 3 до 1.

При этом количество ложноположительных результатов осталось равным 1. Таким образом, для данной задачи порог 0.24 оказался более подходящим, чем стандартный порог 0.50, поскольку основным приоритетом является обнаружение злокачественных опухолей.
